# Codex 额度与全局重置概率监控 v1.5.0

[English README](README.md) · [预测方法及局限](docs/FORECAST_METHOD.md)

Edge / Chrome 的轻量悬浮面板，适合左右分屏和多个 ChatGPT 标签页。

## 新增功能

- 原有 **5 小时、7 天额度百分比、进度条、重置时间、倒计时** 全部保留。
- **新增「额外全局重置」**：显示第三方网站估算的**未来 24 小时、48 小时发生临时全局额度重置的概率**，以及模型置信度和数据更新时间。
- 保留电脑整机物理内存占用、颜色警示、独立标签页开关、拖动、折叠、输入区域避让和跨标签页缓存。
- 不弹窗、不播放提示音、不发送系统通知；不自动使用重置卡。

**非常重要：** 这两项概率只针对 Tibo / OpenAI 可能不定期宣布的**额外全局重置**，不针对账户原有的 5 小时 / 7 天自然重置，亦不包含发放“存储重置卡”。概率是实验性第三方预测，**不是 OpenAI 官方承诺、不是具体到账时间，也不保证适用于你的账户**。

**来源：** [codex-reset.com](https://codex-reset.com/) 的[公开 JSON API](https://codex-reset.com/developers/)。按其公开条款，插件在显示概率的同一位置附有「数据: codex-reset.com」链接。我们没有把第三方模型重新包装为自研算法，也没有混合其他网站的不同统计口径。

## 安装与更新

0. [下载 v1.5.0 安装 ZIP](dist/codex-quota-monitor-v1.5.0-install.zip)，在 GitHub 页面点 **Download raw file（下载原始文件）** 后解压。
1. 在 Tampermonkey 管理面板里**停用旧版 v1.4**（否则可能出现两个面板）。
2. 解压本项目的 v1.5 安装 ZIP，在 Tampermonkey → 实用工具 → 导入 `Codex_Quota_Bars_Web_CN_v1.5.user.js`。
3. 原先安装过 v1.4 Edge 内存扩展的，请到 `edge://extensions` 移除旧的本地 RAM 扩展，再启用「开发人员模式」，选择「加载解压缩的扩展」。
4. 选择新安装包中的 `Edge_RAM_Forecast_Bridge_v1.5` 文件夹（**里面有 `manifest.json`**），不是 ZIP 文件。不要随意移动或删除解压后的文件夹。
5. 刷新 chatgpt.com。等待额度、预测与内存三部分加载。

**为什么要更新 Edge 扩展？** ChatGPT 页面可能因为 CSP 安全策略阻止跨站访问。脚本先尝试直接读取预测站的免费 API，失败时由 v1.5 扩展代为只读获取。v1.5 扩展除原有 `system.memory` 外，新增唯一一项站点权限 `https://codex-reset.com/*`，不会读取历史、其他网站或者上传你的额度/内存数据。

如果不安装扩展：额度功能仍能工作；整机内存无法显示，预测功能取决于网页是否允许跨域请求。

## 使用操作

- `×`：**只关闭当前标签页**的小面板；`Ctrl + Alt + Q`：当前标签页重新打开/关闭。
- `−` / `+`：折叠或展开。拖动标题改动当前标签页的位置，双击标题回默认位置。
- 刷新箭头：立即检查额度，并在符合数据源最短请求间隔时更新额外重置概率。
- 额度、内存达到阈值时仅变色，不弹通知。概率本身不会触发“快要重置”的弹窗。

## 数据怎么刷新？

- 5 小时和 7 天账户额度：约每 **2 分钟**刷新一次，可用标签页之间共享缓存。
- 电脑内存：约每 **30 秒**查询一次（仅面板显示且标签页活动时）。
- 第三方概率：约每 **20 分钟**更新一次；遵守数据源至少间隔 1 分钟的要求，避免多个标签页同时重复请求。
- 如果第三方接口失败或数据日期过旧，会显示「预测暂不可用」或「数据已过期」，**不会把历史百分比当成实时概率**。新旧两种时间的概率均由第三方模型计算，本站不会自造数值。

## 隐私与限制

- **不会向预测网站发送**：ChatGPT 登录令牌、额度剩余百分比、聊天记录、电脑内存数据、用户 ID。
- 只会向 `https://codex-reset.com/api/forecast` 发起固定 HTTPS GET，不带 Cookies、不发送 Referrer。访问外部网站时，对方仍能看到你的**公网 IP 和常规请求信息**。
- 额度数据来自 ChatGPT 非公开承诺稳定的接口，未来可能失效；预测数据依赖第三方提供方，不能保证准确或一直可用。
- 扩展只读取电脑**整机**物理内存，不是 Edge 各标签页分别占用的精确数据。
- 关闭面板后不会在后台持续抓取预测；此工具也**不会全天候监控或代替官方重置公告**。

出现问题时，请优先检查 Edge 扩展和 Tampermonkey 是否都已启用。请不要在 GitHub Issue 上传任何令牌、Cookie、私人对话或完整账号数据。
