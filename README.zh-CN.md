# Codex Quota Monitor v1.4

[English README](README.md)

> GitHub source ZIP: use `userscript/` and `edge-extension/`. Release install ZIP: use the root `.user.js` and `Edge_RAM_Bridge_v1.4/` folder.

Codex Web 额度监控 v1.4（Edge / Chrome）  

新版目标：保留 v1.3 的 5 小时、7 天真实额度以及标签页独立开关；额度低时仅变色；在同一小面板中显示整台电脑物理内存。  

第一部分：更新 Tampermonkey 脚本（必装）  
1. Tampermonkey 管理面板 -> 停用/删除旧版 v1.3，避免同时显示多个面板。  
2. 解压 ZIP，并在 Tampermonkey -> 实用工具 -> 导入 Codex_Quota_Bars_Web_CN_v1.4.user.js。  
3. 刷新 chatgpt.com 的页面。即使不安装第二部分，额度显示也仍可使用；内存行会显示“需装内存组件”。  

第二部分：连接电脑的真实物理内存（可选，但要显示整机内存必须安装）  
1. 打开 Edge 的 edge://extensions。  
2. 开启左下角/侧栏的“开发人员模式”。  
3. 点击“加载解压缩的扩展”，选择解压文件夹 Edge_RAM_Bridge_v1.4（内有 manifest.json）。  
4. 刷新 ChatGPT 页面。约 1 秒内会显示“电脑内存 XX% · 已用/总量 GB”。  
5. Chrome 用户在 chrome://extensions 同样操作。  
注意：必须选择包含 manifest.json 的“文件夹”，不要直接选择 ZIP 文件。  
若企业策略限制加载本地扩展，内存不会显示，但原额度功能不受影响；不尝试绕过企业管控。  

布局与控制  
- × 关闭当前标签页面板；Ctrl+Alt+Q 仅在当前标签页重新打开/关闭。  
- − / + 折叠与展开；拖动标题更改本标签页的位置；双击标题恢复默认位置。  
- 面板坐标和开关都是标签页独立存储，刷新后保留；窗口变窄会自动限制在可视范围。  
- 只有在焦点输入区与面板重叠时才尝试临时挪开；不因鼠标移动或滚动持续跳动。  
- 额外避免多页频繁请求额度：同域标签页共享最近一次成功读取的【百分比与重置时间】，不存令牌；2 分钟周期。  

仅颜色警示，没有弹窗、声音、系统通知、桌面悬浮气泡：  
- 5 小时剩余 <=30% 橙色，<=10% 红色。  
- 7 天剩余 <=20% 橙色，<=5% 红色。  
- 整机内存已用 >=80% 橙色，>=90% 红色。  

真实值与限制  
- “电脑内存” = 物理内存总量 - 系统可用内存；含 Windows 和其他程序，不等于 Edge 进程独占内存，也不一定与任务管理器每一项统计完全一致。  
- 普通网页 / Tampermonkey 没有权限获取整机内存，因此需要本 ZIP 内仅持有 system.memory 权限的 Edge 本地扩展。  
- 内存读取只在显示的 ChatGPT 标签页请求；每 30 秒刷新一次；隐藏标签页与关闭面板暂停请求。  
- 扩展不会访问 ChatGPT 登录令牌或请求任何网络域名。桥接数据仅在 chatgpt.com 本页传输，不向第三方发送。  
- 额度继续使用 ChatGPT 非公开承诺稳定的接口，可能随版本改变；接口不返回的窗口显示“未提供”，不会编造数据。  
- 多标签页减少重复刷新采用 best-effort 的短期锁：在极少数同时启动时可能发起两次只读请求，不能保证严格零重复。  
- 不提供每个进程/标签页分别使用多少 RAM 的精确列表，也不会替你自动关闭窗口。  

故障排查  
- 额度能显示但内存显示“需装内存组件”：检查本地扩展是否已启用，刷新页面。  
- 内存显示“内存不可读”：检查 Edge 版本与扩展错误/权限。  
- 关掉面板忘记打开：按 Ctrl+Alt+Q。  
- 页面提示“刷新失败”：可看浏览器控制台 `[Codex Quota Bars]` 错误，可能是额度接口不可用。
