# Codex 额度监控 v1.6.0：贴边双环悬浮球

[English README](README.md) · [预测来源及局限](docs/FORECAST_METHOD.md)

这是一个非官方的 Edge / Chrome + Tampermonkey 小工具，适合 **左右分屏、长期阅读和多个 ChatGPT 标签页**。

![v1.6 双环和详情示意（模拟数据）](docs/images/v1.6-simulated-preview.png)

*图片为模拟浏览器测试的演示数据，不是任何真实账户额度。*

## 交互方式

- **平时：贴边隐藏。** 仅保留宽约 13px 的细小手柄；不会挡住网页文字和输入框。所有状态按**标签页分别保存**。
- **悬停：小球滑出。** 两个环分别表示 **7 天**和 **5 小时**剩余额度；中心明确显示 `5h 剩余%`、`7d 剩余%` 和 **7 天重置日期、时刻**。下方附有仅在悬停时可见的 24h/48h 第三方额外重置概率及来源链接。
- **单击球体：打开紧凑详情。** 包含两项额度精确百分比、重置时刻和倒计时、预测更新时间及置信度，以及电脑整机 RAM 百分比与用量。弹窗宽约 282px，鼠标点击空白处或按 `Esc` 收回贴边。
- **RAM 超过 90% 时**，小球出现红色 RAM 警示；90% 及以下不在小球里占用位置。点击详情仍可随时查看 RAM。
- **拖动详情标题或贴边手柄**改变贴边位置，支持左右两侧；双击标题恢复默认右侧位置。
- `×`：真正隐藏**当前标签页**监控；`Ctrl + Alt + Q`：恢复/再关闭本标签页。关闭状态刷新后仍保持。
- 不弹窗、不播放声音、不发系统通知，也不会关闭浏览器标签页。

## 安装与更新（Windows Edge）

1. 下载并解压 [`v1.6.0 安装包`](dist/codex-quota-monitor-v1.6.0-install.zip)，保留在一个固定位置。
2. Tampermonkey 管理面板中**停用旧版**，导入 `Codex_Quota_Bars_Web_CN_v1.6.user.js`，然后启用。
3. 若你已经安装并正常使用 v1.5 的 `Codex RAM and Reset Forecast Bridge`，其消息协议和权限与 v1.6 兼容，**无需为这次外观更新重新安装**。
4. 新用户：打开 `edge://extensions`，开启开发人员模式，选择 **加载解压缩的扩展**，选中 ZIP 解压后的 `Edge_RAM_Forecast_Bridge_v1.6` 文件夹（其中应有 `manifest.json`、`bridge.js` 和 `background.js`）。
5. 刷新 `https://chatgpt.com/`，留意窗口侧边一条很细的触发柄；悬停后小球会滑出。若之前关闭过监控，可按 `Ctrl + Alt + Q` 恢复。

## 概率为什么可能暂时不可用？

v1.6 **优先请求已安装 Edge 扩展的后台服务**，失败后才尝试 ChatGPT 页面的跨域只读 GET，避免单纯等待网页跨域请求超时。接口失败后有有界自动重试、跨标签页缓存和明确的状态信息。

**正常情况下不需要手动打开预测网站。** 但如果预测源自身不可达、回应过期、遭遇网站安全挑战或本地网络限制，脚本无法保证获取成功。打开预测网站后恢复只能说明网络/站点状态可能改变，**不能证明一定是浏览器 Cookie、缓存或插件被拦截**。

概率来源：[codex-reset.com](https://codex-reset.com/) 公开数据，仅预测可能的**额外全球额度重置**，不包含正常 5h/7d 到期、存储重置卡或个性化到账资格。预测非 OpenAI 官方保证；不会制造缺失的百分比。

## 刷新与隐私

- 5h / 7d 额度：约 2 分钟检查一次；同域多标签页以短期缓存降低重复查询。
- 物理内存：有可见活动页面时约 30 秒读取一次，不扫描单独进程；后台页或真正关闭的页面不会主动请求。
- 社区预测：成功后约 20 分钟检查一次；失败时有界退避，遵守至少 1 分钟的同浏览器请求间隔。
- 用户脚本仅访问当前已登录的 ChatGPT 额度接口。访问第三方预测站时固定使用公开 GET、`credentials:'omit'`、无 Referrer，**不发送**账号令牌、额度值、聊天内容和内存数据；预测站仍能看到访问 IP 及常规请求元数据。
- 物理内存使用率是 `capacity - availableCapacity`，与 Windows 任务管理器可能因口径不同略有差异。
- 额度接口不受官方承诺稳定；第三方预测 API 可能变化、不可用或概率失准，均会明确展示未知状态。

此项目在 MIT 许可下开源，不隶属于 OpenAI 或预测服务商。报告问题时请勿上传 Cookies、账号令牌或私人对话。
